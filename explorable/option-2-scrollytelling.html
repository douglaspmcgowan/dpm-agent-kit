You hired an assistant with no memory
and infinite willingness to act.

First, the picture in plain terms. A "coding agent" is an AI you talk to in a terminal that can read your files, run commands, and edit code on its own. It is sharp and tireless, but it forgets everything the moment the chat ends, and it will do whatever you ask the instant you ask it. This kit is the small set of files that fixes both problems. Scroll through the five parts. Each one has a control you can poke.

Pillar 01

CLAUDE.md

the standing contract

Five parts, one loop.

Standing instructions keep the assistant on-voice and honest. Guardrails make "infinite willingness" safe. Memory and a task file beat the forget-everything problem. Skills bottle your expertise so you teach a workflow once. The workflow is how you actually drive it: one long conversation, handed off cleanly, day after day.
