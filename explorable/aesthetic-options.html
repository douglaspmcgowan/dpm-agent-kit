dpm-agent-kit // aesthetic options

Twenty-four web design languages, each rendering the same content so you can compare the feel head-to-head. The first eight are the originals; the rest pull from real palettes, indie portfolios, and named design movements. Click the tabs on any card to walk that aesthetic through five page archetypes.

Every card carries five base pages — Hero, List, Article, Dashboard, Form — styled by that card's design language. Tell me which direction (or a mix) and I'll rebuild all four explorables in it.

Fonts load from Google Fonts, so view this online; offline it falls back to system fonts and the type comparison is muted.

Font pairings

The same heading, body paragraph, and code line rendered in sixteen pairings — grouped by aesthetic mood. The display font carries the headings; the body font carries the prose. Swapping these two is the single biggest lever on whether something reads as AI-generated or designed.
