Apply [[voice-profile]] rules to READMEs, docs, setup guides, and HTML copy — not just explicit
"essays" or "emails." Technical documentation is published and read by an audience; it shapes how
people perceive the author just as much as a cover letter does.

**Why:** An agent shipped a README that skipped the voice rules because it framed the file as "just
a doc." AI-sounding constructions ("it's X, not Y," padded openers, hedged assertions) appeared in
public copy on a live site.

**How to apply:** The trigger for reading `voice.md` is any output that could appear on a page
someone else reads — READMEs, setup guides, docstrings in public repos, PR descriptions, and HTML
site copy all qualify. After drafting, self-audit for the banned constructions before delivering.
